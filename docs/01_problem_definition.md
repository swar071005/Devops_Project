# Task 1 — Problem Definition

## Problem
Manual library records make it difficult to track book availability, issue history and returns. The proposed system digitizes these operations.

## Target Users
- Librarian/Admin
- Students

## Objectives
- Maintain centralized book records.
- Provide create, view, update and search functions.
- Automate issue and return status.
- Provide a summary dashboard.
- Establish an automated DevOps delivery lifecycle.

## MVP Scope
1. Book CRUD
2. Search
3. Issue
4. Return
5. Status tracking
6. Dashboard
7. Health endpoint
